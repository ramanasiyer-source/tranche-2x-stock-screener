# 📈 1-Year 2x Stock Screener & Predictive Research Engine

A machine learning & statistical research tool designed to identify US Small/Mid-Cap stocks ($1B–$10B market cap) with high probability to double ($2\times$) in price over a 12-month horizon.

---

## 📂 Project Structure

* `stock_screener.py`: The Python data pipeline, yfinance fetcher, fundamental feature engineer, and Random Forest 2x Conviction ML model.
* `data/stock_screener_cache.json`: Local cache of historical financial statements, market caps, and price data.
* `README.md`: System specifications, project ideas, and architecture documentation.

---

## 🚀 How to Run

```bash
python3 stock_screener.py
```
